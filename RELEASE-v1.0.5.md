Project Hub 1.0.5 includes Sonora 1.0.1 with audio driver setup.

Download `Project-Hub-Setup-1.0.5-x64.exe`, select Sonora, and follow **Audio setup**. It detects installed virtual cables and offers missing ones. The full original base VB-CABLE package is included for chat output. Hi-Fi Cable, used for a separate music feed, downloads directly from VB-Audio when selected; this step requires Internet access even for an offline Sonora package.

- Click **Install** to open the verified original vendor installer and approve the Windows administrator prompt.
- Existing drivers, Sonora profiles, connections, routing and recordings are preserved.
- Restart Windows after driver installation. The computer never restarts automatically.
- Reopen **Audio drivers** in Project Hub or **Audio driver setup** in Sonora Connections to check again or finish later.
- First launch also checks missing drivers, including installations made using an older Hub. Background app updates do not start driver installers.

VB-CABLE and Hi-Fi Cable are VB-Audio donationware, separate from Sonora. Origin: [VB-CABLE](https://www.vb-cable.com/) and [Hi-Fi Cable](https://vb-audio.com/Cable/). All participation is welcome; [licenses and donations](https://vb-audio.com/Services/licensing.htm). Paid A+B and C+D packages are not included.

Available versions: Sonora 1.0.1, Worktable 2.0.1, PadForge 0.2.2 and Velvet 1.4.0. Windows 10/11 x64. Internet required. The Windows installer is unsigned.

Validation: 323 Sonora checks across 14 suites, 21 package checks, 24 driver-helper checks, eight setup-process checks and 56 Hub tests. The real setup-process fixture displays its window without a console. Driver setup was rendered at normal and small-screen sizes. Native selected-tool installation, existing-app reuse, 22 installed-Hub desktop checks, eight existing-app checks and uninstall passed. An isolated Sonora update preserved profiles, connections, routing and recordings, verified the bundled driver ZIP, checked both existing drivers and ran the installed setup command quietly. No driver was installed, removed or rebooted on the test PC; fresh-PC kernel-driver installation remains unverified.
